# Book Catalog (`book_catalog`)

Навчальний проєкт з дисципліни програмування мовою Dart.

## Лабораторна робота №1: Функції та колекції

Консольний застосунок для розбору, перевірки, фільтрації, групування та агрегації записів про книги без використання класів (на базі `Record`, `List`, `Map` та функціональних конвеєрів `Iterable`).
