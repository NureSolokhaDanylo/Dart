# Book Catalog (`book_catalog`)

Навчальний проєкт із розроблення програмного забезпечення мовою **Dart** (SDK `^3.13.2`).

---

## Лабораторна робота №1: Функції та колекції (`branch: lab1`)

Консольна програма для безпечного розбору, валідації, фільтрації, групування, сортування та агрегації записів предметної області **«Каталог книг бібліотеки»** без використання класів (`class`).

---

## Лабораторна робота №2: Об’єктно-орієнтована модель предметної області (`branch: lab2`)

Перенесення функціональної моделі Лабораторної роботи №1 на повноцінну об’єктно-орієнтовану архітектуру зі збереженням зворотньої сумісності всіх функцій першої роботи.

### 1. Обґрунтування вибору архітектури та типів даних

1. **Модульна багатофайлова ООП-архітектура**:
   - `lib/book_catalog.dart` — містить усі функції та іменовані записи ЛР1 і виступає головною бібліотечною точкою реекспорту (`export`) модулів ЛР2;
   - `lib/oop_models.dart` — базовий контракт `Identifiable`, розширене перелічення `BookGenre` та незмінний клас-сутність `Book` із первинним константним конструктором Dart 3.13 (`class const Book({...})`), іменованим конструктором `Book.fromCsv`, фабричними конструкторами `Book.cached`, `Book.fromCsvCached`, `Book.fallback`, обчислюваними гетерами та перевизначенням `==` і `hashCode`;
   - `lib/book_hierarchy.dart` — запечатаний клас `sealed class BookFormat` із 4 підтипами (`PrintedFormat`, `EBookFormat`, `AudioBookFormat`, `CollectorFormat`), поліморфними методами та вичерпними `switch`-виразами без `default`;
   - `lib/mixins_and_extensions.dart` — домішка `mixin CatalogExportable on Identifiable` (підмішана до класів із різних гілок ієрархії: `Book` та `ReaderLoanTicket extends CirculationDocument`) і методи розширення (`extension`) на `String`, `DateTime` та `Iterable<Book>`;
   - `lib/repository_and_patterns.dart` — узагальнене сховище `Repository<T extends Identifiable>`, функції повернення та деструктуризації записів (`Record`), зіставлення зі зразком з охоронцями `when` та формування ООП-звіту через `StringBuffer`.

2. **Вибір типів даних у ЛР2**:
   - **Незмінний клас `Book` з первинним конструктором Dart 3.13 (`class const Book`)**: замінює неструктурований кортеж інкапсульованим об’єктом із поведінкою, кешуванням екземплярів за `id` та перевизначеною структурною рівністю (`operator ==` і `Object.hash` у `hashCode`).
   - **Запечатаний клас `sealed class BookFormat`**: моделює закриту ієрархію носіїв видання (друковане, електронне, аудіокнига, колекційне), що дозволяє компілятору статично перевіряти вичерпність `switch`-виразів без гілки `default`.
   - **Розширене перелічення `enum BookGenre`**: замінює рядкові літерали жанрів із ЛР1 типобезпечним переліченням із власними `final`-полями (`displayName`, `deweyCode`, `maxLoanDays`, `isTechnical`) і методами.
   - **Узагальнене сховище `Repository<T extends Identifiable>`**: інкапсулює колекцію `Map<String, T>` для швидкого пошуку за ідентифікатором $O(1)$ і працює з будь-якими підтипами `Identifiable` (`Book`, `ReaderLoanTicket`).

### 2. Обґрунтування використання `!`, `late` та `dynamic`

У всій кодовій базі проєкту (як у модулях ЛР1, так і в ООП-модулях ЛР2):
- **Оператор `!` (null assertion operator)** — **не використовується (0 входжень)**. Усі перевірки на `null` виконуються через локальне звуження типів (type promotion), оператор `??`, метод `.whereType<T>()` та зіставлення зі зразком (pattern matching).
- **Ключове слово `late`** — **не використовується (0 входжень)**. Усі поля класів оголошені як `final` та ініціалізуються у конструкторах.
- **Тип `dynamic`** — **не використовується (0 входжень)**. Усі узагальнені класи, колекції, записи та функції мають строгі статичні типи.

### 3. Обґрунтування сторонніх залежностей із `pub.dev`

У секції `dependencies` сторонні пакети відсутні (використано виключно стандартну бібліотеку `dart:core`).

У секції `dev_dependencies`:
1. **`lints: ^6.0.0`** — офіційний набір правил статичного аналізатора (`package:lints/recommended.yaml`). Альтернативи (`very_good_analysis`, `flutter_lints`) відхилені на користь офіційного стандарту Dart SDK.
2. **`test: ^1.25.6`** — стандартний фреймворк модульного тестування для запуску тестів через `dart test`.
